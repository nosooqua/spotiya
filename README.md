# spotiya

[![Build and test](https://github.com/klockky/spotiya/actions/workflows/ci.yml/badge.svg)](https://github.com/klockky/spotiya/actions/workflows/ci.yml)

Spotify Connect для Яндекс Станций: музыка, голосовое управление, сенсорные кнопки
и визуализация. AirPlay 2 устанавливается отдельным дополнением.

Нужны Spotify Premium и root-доступ к колонке. Получение root, прошивка
и первоначальная активация станции в проект не входят.

## Поддерживаемые устройства

| Колонка | Профиль | Голосовое управление | Кнопки и жесты | Подсветка и визуализация |
| --- | --- | --- | --- | --- |
| Мини 1 (YNDX-0004) | `mini1` | Да | Штатное управление; отдельного драйвера Spotiya нет | Нет |
| Мини 2 | `mini2` | Да | Пауза, громкость, переключение треков | Эффекты кольца, громкость и спектр на дисплее |
| Станция 2 | `midi` | Да | Сенсор: касания, свайпы, удержание громкости | Эффекты управления и музыкальная визуализация на панели |
| Станция Миди | `cucumber` | Да | Сенсор: касания, свайпы, удержание громкости | Эффекты и визуализация на кольце, громкость на часах |

Таблица описывает возможности текущего кода. Работа голосовых команд и AirPlay
зависит от прошивки; для других моделей полная поддержка не заявлена.
Профиль `midi` относится к **Станции 2**, а `cucumber` — к **Станции Миди**.

## Возможности

| Возможность | Что доступно |
| --- | --- |
| Spotify Connect | Воспроизведение из приложения Spotify, вход по короткому коду |
| AirPlay 2 | Музыка с iPhone, iPad и Mac; переключение между Spotify и AirPlay |
| Голос | Поиск музыки, пауза, продолжение, смена трека; приглушение Spotify при обращении к Алисе |
| Сенсорное управление | Касания, свайпы и повтор громкости при удержании на Станции 2 и Миди |
| Визуализация | Спектр Spotify и AirPlay; на Станции 2 и Миди включён по умолчанию, на Мини 2 включается вручную |
| Терминальный интерфейс | Текущий трек, поиск, управление, выбор профиля и дополнений |
| Настройки | Общее или отдельные имена Spotify и AirPlay, отключение голоса, кнопок и визуализации |
| Обслуживание | Автозапуск, сохранение входа, диагностика и обновление с откатом при ошибке |

## Быстрая установка и обновление

В **root-терминале колонки** (SSH или `adb shell`) вставьте строку целиком,
**вместе со скобками**:

```sh
(set -e; p=/data/opt/spotify-connect/spotiya; [ ! -x "$p" ] || exec "$p" --update; d=$(mktemp -d /tmp/spotiya.XXXXXX); trap 'rm -rf "$d"' EXIT; cd "$d"; echo 'Downloading Spotiya...'; get() { LD_LIBRARY_PATH=/system/vendor/quasar/libs /system/vendor/quasar/maind --gst-launch "souphttpsrc location=https://github.com/klockky/spotiya/releases/latest/download/$1 ssl-strict=true ssl-ca-file=/etc/ssl/certs/ca-certificates.crt iradio-mode=false timeout=15 retries=1 ! filesink location=$1" >log 2>&1 && grep -Fq 'EOS: end of stream' log && ! grep -Fq 'ERROR from ' log && [ -s "$1" ]; }; get INSTALL_SHA256SUMS && get install.sh || { echo 'Installer download failed.' >&2; exit 1; }; [ "$(wc -l <INSTALL_SHA256SUMS)" -eq 1 ] && grep -Eqx '[0-9a-f]{64}  install\.sh' INSTALL_SHA256SUMS && sha256sum -c INSTALL_SHA256SUMS || { echo 'Installer checksum mismatch.' >&2; exit 1; }; sh install.sh)
```

Команда устанавливает последний стабильный [релиз](https://github.com/klockky/spotiya/releases/latest)
или обновляет существующую установку, сохраняя вход и настройки.
Новые возможности из `main` появятся в ней после выпуска релиза.

После установки:

```sh
spotiya tui
```

В интерфейсе нажмите `l` и подтвердите вход по коду. Обновить установленную
Spotiya можно командой `spotiya update`.

### Через ПК

Если быстрая установка недоступна, скачайте ARMv7-архив и `SHA256SUMS` из
[Releases](https://github.com/klockky/spotiya/releases)
или [артефактов Actions](https://github.com/klockky/spotiya/actions/workflows/ci.yml).
На ПК проверьте и распакуйте архив:

```sh
sha256sum -c SHA256SUMS
tar -xzf spotiya-armv7-linux-gnueabihf.tar.gz
```

Передайте его на колонку и запустите установщик через adb:

```sh
adb -s SPEAKER_IP:5555 push spotiya /tmp/
adb -s SPEAKER_IP:5555 shell sh /tmp/spotiya/scripts/install.sh
```

Или через SSH (укажите порт своей колонки):

```sh
tar -cf - spotiya | ssh -p 2222 root@SPEAKER_IP 'tar -xf - -C /tmp && sh /tmp/spotiya/scripts/install.sh'
```

Этот способ также подходит для перехода с 0.9.4, если обновлятор отклоняет
новый архив с сообщением `Unexpected file in release archive`.

## Управление

| Команда | Действие |
| --- | --- |
| `spotiya` или `spotiya tui` | Открыть интерфейс |
| `spotiya login` | Войти по коду |
| `spotiya play "No Surprises"` | Найти и включить музыку |
| `spotiya pause` / `spotiya resume` | Пауза / продолжение |
| `spotiya next` / `spotiya previous` | Следующий / предыдущий трек |
| `spotiya volume 25` | Установить громкость |
| `spotiya voice on` / `off` | Включить / выключить голосовое управление |
| `spotiya controls on` / `off` | Включить / выключить управление кнопками и индикацию действий |
| `spotiya spectrum on` / `off` | Включить / выключить музыкальную визуализацию на Мини 2, Станции 2 и Миди |
| `spotiya release` | Освободить сеанс для штатной музыки |
| `spotiya start` / `stop` / `restart` | Управлять службой |
| `spotiya status` | Показать состояние |

С ПК доступны те же команды через `python3 bin/spotiya --device SPEAKER_IP:5555 COMMAND`.
Нужны Python 3 и adb.

### Клавиши интерфейса

| Клавиша | Действие |
| --- | --- |
| `Space` | Пауза / продолжение |
| `n` / `p` | Следующий / предыдущий трек |
| `+` / `-` | Громкость |
| `/` | Поиск |
| `l` | Вход по коду |
| `v` / `b` | Голос / кнопки вкл/выкл |
| `e` | Музыкальная визуализация вкл/выкл |
| `d` / `a` | Профили / дополнения |
| `r` | Повтор после серии ошибок |
| `x` | Освободить сеанс |
| `q` | Закрыть интерфейс, оставив музыку |

### Голос, сенсор и подсветка

Скажите «Алиса, включи Radiohead», «следующий трек» или «продолжи музыку».
Короткие команды без «Алиса», например «стоп» и «пауза», работают при наличии
их поддержки в прошивке и активном сеансе Spotiya.

На Мини 2, Станции 2 и Миди центр переключает паузу, `+`/`−` меняют громкость,
а жест через центр к `+`/`−` переключает треки. На Станции 2 и Миди удержание
`+`/`−` повторяет изменение громкости. Кнопка микрофона остаётся у Алисы.
После окончания сеанса сенсор возвращается штатному плееру.

При обращении к Алисе Spotify и AirPlay плавно приглушаются, затем возвращаются
к прежней громкости. Приглушение работает и при выключенной визуализации.

Для Spotify и AirPlay используются одинаковые кнопки и голосовые команды:
пауза, продолжение, следующий и предыдущий трек. Для обратного управления
AirPlay нужно обновлённое дополнение; выполнение команд зависит от приложения
на устройстве-отправителе. Пауза сохраняет AirPlay-сеанс для продолжения.
Запрос конкретной песни или исполнителя запускает поиск Spotify.

На **Станции 2** для музыкальной визуализации выключите «Световую заставку»
в приложении «Дом с Алисой». На **Миди** музыка визуализируется на кольце,
а изменение громкости временно отображается на часах. На Станции 2 и Миди
музыкальная визуализация управляется отдельно через `spectrum on` / `off`
(клавиша `e` в TUI) и продолжает работать при `controls off`.

## AirPlay 2

Установите и включите дополнение через `spotiya addons` или командами:

```sh
spotiya addon install airplay
spotiya airplay on
```

Выберите колонку в меню AirPlay устройства в той же сети. Spotify и AirPlay
автоматически уступают друг другу воспроизведение.
Для выключения: `spotiya airplay off`.
На Миди нужен обновлённый пакет AirPlay: пакет версии 0.9.4 несовместим с её прошивкой.

## Профиль и имя колонки

Профиль выбирается автоматически. Посмотреть его можно командой `spotiya profile`,
изменить — в интерфейсе клавишей `d` или вручную:

```sh
spotiya profile select midi       # Станция 2
spotiya profile select cucumber   # Станция Миди
spotiya profile select auto       # автоматический выбор
```

По умолчанию имя в Spotify и AirPlay берётся из профиля. Его можно изменить:

```sh
spotiya name "Гостиная"
spotiya name spotify "Гостиная Spotify"
spotiya name airplay "Гостиная AirPlay"
spotiya name reset
```

Смена профиля или имени перезапускает работающий приёмник.
Настройки сохраняются после перезагрузки и обновления.

## Если что-то не работает

| Команда | Для чего |
| --- | --- |
| `spotiya doctor` | Проверить установку, сеть и доступность функций |
| `spotiya doctor report` | Сохранить диагностический отчёт без токенов |
| `spotiya retry` | Повторить воспроизведение после серии ошибок |
| `spotiya restart` | Перезапустить приёмник |
| `spotiya update` | Установить последний стабильный релиз |

Журнал: `/tmp/spotify-connect.log`. При сообщении об ошибке приложите версию
Spotiya, модель колонки и отчёт `doctor`.

## Сборка

Нужны Linux, Rust, C-компилятор и заголовки ALSA. Проверки и сборка ARMv7-пакета:

```sh
cargo test --locked
make -C controls/mini2 check
scripts/bootstrap-arm.sh
scripts/build-arm.sh
scripts/package.sh
```

Полный набор проверок — в [CI](.github/workflows/ci.yml).
Воспроизведение обеспечивает [librespot](https://github.com/librespot-org/librespot).
